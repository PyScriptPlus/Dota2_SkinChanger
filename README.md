## Overview

**Dota 2 Skin Changer** is an open-source project designed to bring a new level of cosmetic customization to Dota 2.

Built from the ground up using **C++** and **Dear ImGui**, this project provides a dedicated interface for exploring and accessing a wide collection of Dota 2 skins, cosmetics, and map environments.

The project focuses on delivering a powerful, intuitive, and responsive experience while making cosmetic customization accessible through a clean graphical interface.

This is a passion-driven project with a strong focus on performance, functionality, and attention to detail.

## Features

- **Hero Cosmetics** — Explore and access Dota 2 hero skins and cosmetic items.
- **Map Customization** — Unlock and customize available Dota 2 map environments.
- **Modern GUI** — A custom-designed graphical interface powered by Dear ImGui.
- **C++ Performance** — Built with C++ for efficient and responsive execution.
- **All-in-One Experience** — Manage cosmetic customization through a single application.
- **Open Source** — Public source code for developers and enthusiasts to explore.
